## 1. Why - 목적
- 할 일을 상태(todo/doing/done)로 시각화하여 실행 현황 파악
- 일일 할 일을 주간계획과 1년 목표에 연결해 목표 달성 경로 가시화
- 할 일 완료가 주간 진행률에 자동 반영되어 수동 집계 제거
- 장기 목표와 일일 실행의 단절 해소

## 2. Who - 타깃 사용자
- 1년 단위 목표를 세우고 일일/주간 단위로 실행하려는 개인
- 기존 할 일 앱에서 목표와 할 일이 분리되어 불편한 사용자
- 칸반 방식(드래그 앤 드롭)을 선호하는 사용자

## 3. User flow
- 1년 목표 생성
- 주간계획 생성 → 1년 목표 선택하여 연결
- 할 일 생성 → 주간계획 선택하여 연결
- 보드에서 할 일 확인 (todo / doing / done 컬럼)
- 할 일 카드를 드래그 앤 드롭으로 컬럼 이동 → 상태 변경
- 상태가 done으로 변경 → 연결된 주간계획 진행률 자동 갱신
- 주간계획 진행률 확인
- 할 일/주간계획/1년 목표 수정 또는 삭제

## 4. 기능요구사항

### P0 - 핵심기능
- 할 일 CRUD
  - 생성: 제목(필수), 주간계획 연결(필수)
  - 수정: 제목, 연결된 주간계획
  - 삭제: 삭제 전 확인
- 상태관리
  - 상태값: todo / doing / done
  - 신규 생성 시 기본값: todo
- 드래그 앤 드롭
  - 카드를 컬럼 간 이동하면 상태 변경
  - 변경 즉시 저장
- 기간 구조
  - 일일: 할 일 (날짜 지정)
  - 주간: 주간계획 (주 단위 기간)
  - 1년: 1년 목표 (연도 단위)
  - 각 기간 단위 CRUD
- 구조 연결
  - 할 일 → 주간계획 (N:1)
  - 주간계획 → 1년 목표 (N:1)
  - 상위 항목 삭제 시 하위 항목 처리 정책 적용 (삭제 전 하위 항목 존재 안내)
- 주간 진행률 자동 반영
  - 진행률 = done 할 일 수 / 전체 할 일 수 × 100
  - 할 일 생성/삭제/상태 변경 시 자동 재계산
  - 주간계획 화면에 진행률 표시

### P1 - 추가기능
- 1년 목표 진행률
  - 연결된 주간계획 진행률 기반 자동 계산
- 기간별 보기
  - 일일 / 주간 / 1년 뷰 전환
- 필터
  - 상태별, 주간계획별, 1년 목표별
- 할 일 마감일 지정
- 컬럼 내 카드 순서 변경 (드래그 앤 드롭)
